## 3. Method notes and threats to validity

- The demo ground truth is written by the same author as the rules, so it measures whether each rule fires where intended and stays quiet on the decoys. It is not an estimate of performance on arbitrary code.
- Dependency precision is measured at package level: every advisory OSV returns for a pinned version is reported. Whether the vulnerable function is reachable is not analysed (see Limitations in the README).
- Real-world repositories have no ground truth; the table reports volumes and exploit signals. Spot checks of the P0 items (KEV-listed CVEs, taint-confirmed injections) are described in `docs/REPORT_CONTENT.md`.
- EPSS scores change daily and OSV advisories are added continuously, so re-running will change the counts.
